# 設計ハンドオフ・アーカイブ（claude.ai/design）

このディレクトリは、本リポジトリ「探究学習ポータル」の母体となった **claude.ai/design のデザインハンドオフ束**（2026年6月頃）のアーカイブです。本番運用とは無関係で、設計意図の記録・参照用としてのみ保持しています。

## 本番はどこにあるか

公開ページ・管理画面などの本番系はすべて **リポジトリのルート** にあります。

- ルート `index.html` … 公開ページ（本番・正本）
- ルート `admin.html` … 管理画面（本番）

このアーカイブ内の `index.html` / `探究リサーチポータル.dc.html` は claude.ai/design が書き出した **プロトタイプ**（両者は同一内容）であり、本番ページとは別物です。ブラウザで開いて動作させる用途は想定していません（アセットへの相対パスは意図的に据え置いており、本番の `project/` 配下を指しません）。

## 内容

- `chats/` … デザインアシスタントとの会話ログ2本（設計意図の記録。chat1=初期設計、chat2=セミナー/イベントカルーセル追加など続行分）
- `index.html` … プロトタイプ（デザイン兼作業コピー）
- `探究リサーチポータル.dc.html` … 上記の書き出しコピー（`index.html` と同一内容）
- `screenshots/` … デザイン時のスクリーンショット
- `futaba.png` … マスコット画像。制作途中でインライン data URI 化され、プロトタイプ・本番のいずれからも未参照となった孤立アセット
- `.thumbnail` … claude.ai/design のプロジェクトサムネイル

## フォントについて（削除していません）

`project/assets/fonts/` の Meiryo / UDデジタル教科書体（.ttc・計約28MB）は再配布許諾のない商用フォントで、公開リポジトリへの同梱はライセンス上の懸念があります。当初は削除予定でしたが、調査の結果 **本番の `index.html` が `@font-face` で直接参照している**（12〜15行目）ことが判明したため、削除を見送りました。

削除するには、先に本番 `index.html` の `@font-face` 宣言（`project/assets/fonts/*.ttc` を指す4行）を除去し、システムフォントへのフォールバックを受け入れる判断が必要です。**要ユーザー確認。**
